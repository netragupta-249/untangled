Design a visually striking, premium **desktop web application** called **“Untangled”**, inspired by the attached reference image.

IMPORTANT:
Use the reference only for its visual language: soft gradients, rounded cards, friendly premium aesthetic, whitespace and elegant onboarding feel.

Do NOT copy the mobile layout.
Do NOT create phone mockups.
Do NOT create a mobile application.

Design specifically for a **1440 × 900 laptop/desktop viewport**.

---

# PRODUCT

Brand name:

**Untangled**

Hero tagline:

**50 messages. One clear plan.**

Core concept:

Untangled is an AI-powered campus information assistant that transforms a chaotic stream of college announcements into a clear, prioritized and actionable plan.

It identifies:

• What needs attention now
• What the student needs to do
• Approaching deadlines
• Schedule conflicts
• Cancelled or changed activities
• Limited-seat opportunities
• Unexpected opportunities
• Duplicate announcements
• Missing or incomplete information

The core transformation should visually communicate:

**CHAOS → AI → CLARITY → ACTION**

The product should feel like a real consumer technology product that students would genuinely want to use.

---

# VISUAL DIRECTION

Create a **colorful premium aesthetic**.

The design should retain the soft, elegant feeling of the reference but be noticeably more vibrant and visually engaging.

### Base colors

Use:

• Warm ivory / cream backgrounds
• Soft peach
• Coral
• Apricot
• Warm yellow
• Lavender
• Soft violet
• Mint green
• Powder blue

Use dark charcoal/black for primary typography.

Do NOT make the entire interface pastel and washed out.

Use color strategically to create hierarchy and make important information immediately recognizable.

### Suggested visual palette

Background:
Warm ivory / cream

Primary accent:
Coral / peach

Secondary accent:
Soft violet

Highlight:
Sunny yellow

Success:
Fresh mint

Information:
Soft sky blue

Urgent:
Warm coral/red

Use gradients between these colors for hero areas, AI processing visuals and selected states.

Keep the colors soft and sophisticated rather than neon.

---

# COLOR SYSTEM

Create a consistent visual meaning for colors.

🔴 Coral:
Urgent / deadline / immediate attention

🟠 Peach:
Important

🟡 Yellow:
Upcoming / deadline approaching

🟢 Mint:
Completed / confirmed / no action required

🔵 Blue:
Information / schedule

🟣 Lavender:
Opportunities / discovery / AI insights

⚪ Cream:
Neutral information

This makes the interface visually understandable even before reading the text.

# GENERAL DESIGN LANGUAGE

Use:

• Large rounded cards
• 24–32px corner radius
• Generous whitespace
• Soft layered shadows
• Subtle gradients
• Thin borders
• Elegant typography
• Large expressive headings
• Rounded pill badges
• Colorful micro-interactions
• Small icons
• Soft abstract gradient shapes
• Subtle decorative blobs
• Smooth visual hierarchy

Cards should feel tactile and slightly elevated.

Use a mixture of white/cream cards and very lightly tinted cards.

Do not make every card the same color.

---

# TYPOGRAPHY

Use a sophisticated modern sans-serif for most interface text.

Use an elegant display/serif font very selectively for major hero headings if it looks premium.

Headings should be large, confident and expressive.

Example:

**Campus chaos?**
**We've got it untangled.**

Make “untangled” visually distinctive using a subtle gradient or accent treatment.

Avoid excessive bold text everywhere.

# IMPORTANT PRODUCT PRINCIPLES

The interface must communicate these principles visually:

### 1. PRIORITIZE, DON'T HIDE

Less relevant information should still remain discoverable.

### 2. NEVER INVENT

If a deadline or location isn't present:

**“Not mentioned”**

Never estimate or fabricate it.

### 3. SHOW THE SOURCE

Every important piece of extracted information should be traceable to the original announcement.

### 4. AI ASSISTS, STUDENT DECIDES

For conflicts, Untangled highlights the clash but never decides which commitment the student should choose.
