Design a premium, modern **desktop web application** called **“Untangled”**, inspired by the attached visual reference.

IMPORTANT:
Use the reference only for its **visual language and aesthetic**, NOT its mobile layout or content.

The website must be designed specifically for a **laptop/desktop screen**, approximately 1440 × 900 px. Do NOT create phone mockups or mobile screens.

## PRODUCT

Name: Untangled

Tagline:
**50 messages. One clear plan.**

Purpose:
Untangled is an AI-powered campus information assistant that takes a chaotic stream of college announcements and turns them into a clear, prioritized and actionable plan.

It helps students understand:

* What needs attention now
* What they need to do
* What deadlines are approaching
* Which events conflict
* Which opportunities they might miss
* Which announcements contain incomplete information

The product should feel calm and effortless despite dealing with information overload.

---

# VISUAL STYLE

Take strong visual inspiration from the attached reference.

Use:

* Warm off-white / cream background
* Soft peach, blush and subtle yellow gradients
* Large rounded rectangular cards
* Very generous whitespace
* Black/dark charcoal typography
* Minimal interface
* Soft shadows
* Thin subtle borders
* Rounded buttons
* Small colorful status indicators
* Elegant oversized headings
* Friendly, premium, editorial aesthetic
* Soft gradient blobs/abstract shapes used sparingly
* Smooth visual hierarchy

The design should feel like:
**Apple-inspired + modern productivity app + premium student product.**

Avoid:

* Dark mode
* Typical blue SaaS dashboards
* Excessive neon
* Excessive glassmorphism
* Generic AI chatbot appearance
* Corporate/enterprise styling
* Dense tables
* Overly complicated dashboards

Use a sophisticated serif or elegant display font sparingly for major headings if appropriate, paired with a clean modern sans-serif for UI text.
